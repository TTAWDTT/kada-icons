# 咔嗒 · Kada Icons

26 枚贴纸风的彩色图标，全部为透明 PNG。这套图标最初用在桌面客户端的侧栏、菜单和视频分区，采用 AI 生成，并逐枚核对了小尺寸下的显示效果。[oh-bilibili](https://github.com/TTAWDTT/oh-bilibili)

## 使用

把需要的 PNG 复制到自己的项目里。下面的例子把图标放在按钮文字旁边，显示宽度为 24 像素。

```html
<button type="button">
  <img src="./icons/favorite-folder.png" width="24" alt="">
  收藏夹
</button>
```
